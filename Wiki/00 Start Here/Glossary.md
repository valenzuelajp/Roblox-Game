# Glossary

Alphabetical. Link the first use of a term to this page.

| Term | Definition |
|---|---|
| **Anchor room** | A room that always exists in a session and always serves the same function (Foyer, Ballroom, Kitchen, Study, Chapel, Archive, Vault, Attic). Its position changes, but its purpose does not. |
| **Blackwood Lodge** | The working title of the game and the name of the mansion. |
| **Case File** | The shared four-task investigation notebook. Correct answers yield Cinders, progress, and one letter of the Hollow Word. |
| **Cinders** | The end-of-match currency earned from case progress and unspent Shillings. Used for progression and cosmetics. |
| **Clue manifest** | The server-side data record of which clue spawned in which room and container, with the correct answer and item requirement. |
| **Curio Shop** | Madame Vesper's solo pre-match shop. Players spend 100 Shillings on investigator items; the killer uses the same window to stage the crime. |
| **Dead chat** | A separate text channel for dead players. Living players cannot see or hear it. |
| **Detain** | The non-lethal takedown of a killer. Yields the full 100% reward path. |
| **Fate vote** | The post-ritual vote to detain or execute the revealed killers. Proposed, not locked. |
| **First pistol** | The four-bullet revolver awarded when the first Case File task is solved. |
| **Free clue** | The low-quality clue available without an item. Vague, incomplete, sometimes misleading. |
| **Ghost Blueprint** | The original 1926 floor plan found in the Archive. It reveals where the chapel, vault, and task rooms used to be. |
| **Hollow Word** | The five-letter passphrase assembled from four task letters plus the ritual letter. It unlocks the exit. |
| **Item clue** | The definitive clue revealed by the matching investigator item. |
| **Killer** | The cultist hidden among the investigators. One at 6–7 players; two partners at 8–10. |
| **Last Hunt** | The 60-second window after the ritual reveal when the killers get no mark cooldown, a speed boost, and a brief wallhack. |
| **Midnight Shift** | The 14:00 event when one wing of the lodge reconfigures and the chapel/vault open. |
| **Modular wing** | A room that may appear, disappear, or move between sessions. |
| **Pistol vote** | The proposed 15-second vote at 1/4 to choose the first pistol holder. |
| **Proposed** | A recommendation that still needs approval. Not canon. |
| **Ritual** | The 30-second channel at the chapel after all four tasks are correct. Reveals the killers, grants the fifth letter, and triggers the Last Hunt. |
| **Scenario Card** | One of ten possible crimes. Defines the victim, motive, weapon, staging, signature, red herring, and Hollow Word. |
| **Scene clue** | A clue placed by the killer during staging. Not randomized. |
| **Second pistol** | The four-bullet pistol behind three seals in the vault cabinet. Anyone can claim it. |
| **Shillings** | The pre-match shop currency. Everyone starts with 100. |
| **Sigil** | The visible mark the killer binds to an investigator. A physical sigil spawns on the map; breaking it saves the marked player. |
| **Soft-lock** | A state where the Case File or exit becomes impossible to complete. The generator must prevent it. |
| **Supporting clue** | A randomized clue placed by the generator, not the killer. |
| **The Hollow Court** | The cult behind the ritual and the nine disappearances. |
| **The Nine Guests** | The nine people who vanished from Blackwood Lodge ten years before the game. |
| **Vault** | The cellar cabinet that holds the second pistol. Opened by three seals. |
| **Wing** | A group of rooms connected by a shared corridor or staircase. The midnight shift targets one wing. |
