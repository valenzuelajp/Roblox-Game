# Unlocks

> [!important] The rule
> Unlocks are **collection and expression**, never advantage. If an unlock changes what a player knows or can do in a match, it is not an unlock — it is pay-to-win or grind-to-win, and it is forbidden.

## Unlock categories

| Category | Examples | How it unlocks | Gameplay effect |
|---|---|---|---|
| **Casebook** | Scenario pages, victim profiles, Hollow Words, epilogues | Play and solve scenarios | None; lore collection |
| **Cosmetics** | Outfits, hats, glasses, gloves, gun skins | Cinders, badges, rank | None; visual only |
| **Titles** | "The Whole Truth," "Ninth Guest," "Cage Keeper" | Badges | None; display only |
| **Lobby themes** | Rain, fireplace, chapel, archive | Rank, Cinders, events | None; lobby visual |
| **Emotes** | Tip hat, light pipe, check watch, shrug | Rank, Cinders | None; social only |
| **Casebook skins** | Leather, ash, cyanotype, red string | Rank, Cinders | None; UI visual |

## Casebook gates

The casebook is the main unlock track:

- **Encountered:** the scenario's title and silhouette. The rest is redacted.
- **Played:** the victim profile, the staging room, and the public clue themes.
- **Solved:** the true answers, the Hollow Word, and the epilogue.
- **Mastered:** solved with 4/4 tasks and the killer stopped. Adds a gold stamp and a title.

A player who has never played a scenario cannot read its answers in the casebook. This protects spoilers and gives replay value.

## Cosmetic unlock paths

1. **Rank rewards.** One cosmetic per rank tier.
2. **Badge rewards.** A specific cosmetic for a specific achievement.
3. **Cinder shop.** Direct purchase, no randomness.
4. **Seasonal sets.** Direct purchase or event reward; no loot boxes.
5. **Private server rewards.** A small host-only cosmetic; no gameplay effect.

## What never unlocks

- Investigator items.
- Extra bullets.
- Extra health.
- Faster movement.
- Clue locations.
- Killer identity.
- Scenario answers.
- A "premium killer" queue.
- A map that only paying players see.

## Unlock cadence

| Play time | Expected unlock |
|---|---|
| First match | One common cosmetic |
| First case solved | One badge + one casebook page |
| First ritual | One title |
| Rank 5 | One lobby theme |
| Rank 10 | One outfit |
| 10 scenarios solved | Mastery title |
| Seasonal event | One emote or set piece |

The cadence should feel generous early and slower later. The first hour should never feel empty.
