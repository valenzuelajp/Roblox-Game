# Clue Types

> [!info] Type vs. tier
> A clue's **tier** is free or item-gated. A clue's **type** is what kind of evidence it is. A free clue can be a document; an item clue can be a trace. The two axes are independent.

## The eight clue types

| Type | What it is | Tier examples | Best rooms | Counterplay |
|---|---|---|---|---|
| **Document** | A letter, ledger, guest book, will, newspaper | Free: torn page. Item: decoded letter | Study, archive, library | Forgery, missing pages |
| **Physical** | A weapon, tool, clothing, furniture | Free: bloody letter opener. Item: wound detail | Study, kitchen, cellar | Planted weapon |
| **Trace** | Blood, ash, perfume, footprints, wax | Free: smell. Item: UV trail | Hallway, chapel, ballroom | Cleaned or covered |
| **Testimony** | An NPC's statement | Free: overheard rumor. Item: pressed testimony | Kitchen, foyer, garden | Lie, contradiction |
| **Symbol** | Sigil, zodiac, binary, runes, knot | Free: partial mark. Item: full pattern | Chapel, attic, archive | Paint over, rotate |
| **Environmental** | A room's state: cold, locked, moved | Free: cold spot. Item: hidden passage | Any | Killer sabotage |
| **Audio** | A recording, a whisper, a piano note | Free: muffled sound. Item: recorder | Study, ballroom, chapel | Noise, interference |
| **Puzzle-locked** | A container or door with a puzzle | Free: the puzzle. Item: cipher wheel | Vault, cabinet, gate | Time, wrong solution |

## How the types combine

Each task should use **at least two types** so the clue web feels layered:

### Task 1 — Victim
- **Document:** scorched invitation (free).
- **Document:** full guest list (item — camera).
- **Environmental:** portrait plaque (item — camera).
- **Testimony:** Finch's memory of the guest (optional).

### Task 2 — Method
- **Physical:** bloody letter opener (free).
- **Trace:** wound shape (item — magnifying glass).
- **Document:** coroner's note (optional).
- **Testimony:** Cook heard a bell (optional).

### Task 3 — Scene
- **Trace:** strange smell (free).
- **Symbol:** sigil under the rug (item — UV torch).
- **Environmental:** the room is too clean (free).
- **Audio:** the piano note (optional).

### Task 4 — Motive
- **Document:** torn ledger page (free).
- **Document:** decoded letter (item — cipher wheel).
- **Testimony:** Vesper's hint (optional).
- **Symbol:** the cult's mark on the will (item — UV torch).

## Free clue types

Free clues should be **readable at a glance** but **incomplete**:

- A torn document with a partial name.
- A weapon with the wrong blood pattern.
- A smell that could be two things.
- A witness who is clearly scared.
- A symbol with a missing piece.

The free clue must **eliminate one wrong option**. It can be ambiguous about the other two. It must not eliminate the correct option.

## Item clue types

Item clues should reveal a **physical detail** that changes the interpretation:

- The camera's flash reveals the faded plaque.
- The magnifying glass reveals the wound's cross-section.
- The UV torch reveals the blood trail.
- The cipher wheel decodes the letter.
- The recorder plays the last message.

The item clue should be **visual and textual**. A player without the item can still see the free clue; a player with the item sees the truth.

## False clue types

The killer's one false clue should be a **plausible document or physical object**:

- A forged will.
- A planted weapon.
- A letter in the victim's handwriting (forged).
- A photograph with the wrong date.
- A witness statement that contradicts the free clue.

The false clue should not be a symbol or a puzzle-locked clue; those are too easy to verify. It should be something the team can argue about.

See [[False Clues]].

## Testimony clues

NPC testimony is **optional corroboration**, not a requirement:

- It can confirm a true clue.
- It can contradict a false clue.
- It can be wrong because the NPC is scared, bribed, or cult.
- It can be pressed with an item (e.g., the Notebook records the exact wording).

Testimony should never be the **only** way to solve a task. Text players must be able to read it; voice players can hear it.

## Puzzle-locked clues

Some clues are inside puzzle-locked containers:

- A zodiac dial on a desk drawer.
- A binary lock on a strongbox.
- A blood cipher on a diary.
- A rune alignment on a chapel reliquary.
- A knot pattern on a cellar crate.

The puzzle is the **lock**, not the clue. Solving it reveals the clue. The clue still has a free and item layer.

## Clue type distribution

For a 24–28 room map, the target distribution is:

| Type | Count | Notes |
|---|---|---|
| Document | 8–10 | Spread across study, archive, library, bedrooms |
| Physical | 4–6 | Near the body, kitchen, cellar |
| Trace | 4–6 | Hallways, chapel, ballroom |
| Testimony | 3–5 | Staff locations |
| Symbol | 4–6 | Chapel, attic, secret passages |
| Environmental | 3–5 | Any room with a state change |
| Audio | 2–3 | Study, ballroom, chapel |
| Puzzle-locked | 3–5 | Vault, cabinet, gate |

The exact counts scale with the map size and player count.

## Design rules

1. **Every clue type has a text description.** No type is visual-only.
2. **Every clue type has a counterplay.** No type is un-fakeable except the item clue.
3. **Every task uses at least two types.** No task is a single prop.
4. **No type is always true.** Testimony can lie; documents can be forged; traces can be staged.
5. **The item clue is always true.** It is the anchor the team can trust.
6. **The free clue is never a lie.** It can be incomplete, but it must not eliminate the correct option.
7. **The false clue is always the killer's.** It is the only deliberately false evidence.
