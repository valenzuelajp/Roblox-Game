# Patch Notes

> [!info] Player-facing only
> These notes describe changes players can see. Internal design notes live in the development vault.

## 0.1 — First Playable (in development)

**Status:** Not public yet. This is the vertical-slice target.

### Added

- Lobby for 6–10 players with role assignment.
- 30-minute match clock, 6:00 PM to 7:00 AM.
- Solo Curio Shop with 100 Shillings and ten investigator items.
- Four Case File tasks: Victim, Method, Scene, Motive.
- Free clues and item-gated clues.
- Five puzzle families: zodiac, binary, blood cipher, rune alignment, knot/pattern.
- Killer mark, physical sigil, and puzzle rescue.
- First pistol at 1/4, four bullets.
- Second pistol behind three seals.
- Ritual, reveal, Last Hunt, and escape gate.
- Ghost spectator and dead chat.
- Basic results screen with Cinders.

### Known issues

- The map generator occasionally places a decorative prop inside a doorway. It does not block movement.
- Voice chat indicators can lag by one second on mobile.
- The ritual bell can double-play if two players interact at once.
- Some guest-room props clip through the bed frame.
- The evidence board zoom is not available on gamepad yet.

### Planned for 0.2

- Second map wing variant.
- Two more scenario cards.
- Item trading.
- Improved onboarding for the killer role.
- Accessibility pass: screen reader for the Case File and evidence board.
- Performance pass for mobile.

## 0.0 — Prototype

**Status:** Internal.

### Added

- Grey-box lodge with eight anchors.
- Server-authoritative match state machine.
- Basic clue search and answer submission.
- Basic mark and sigil loop.
- Internal playtest build.

### Removed

- The old fifth Case File question. The ritual now reveals the killer.
- The old fixed map. The lodge is procedural.

## How to read these notes

- **Added:** new content or systems.
- **Changed:** existing behavior.
- **Fixed:** bug fixes.
- **Known issues:** confirmed bugs we are still working on.
- **Planned:** not in the build yet. Do not expect it until it appears under "Added."

## Reporting a bug

Settings → Help → Report a Problem. Include the room, the time, and what happened. Do not post scenario answers in the report.
