# Controls

> [!tip] Everything is remappable
> The defaults below are a starting point. You can remap every action in **Settings → Controls**. Mobile and gamepad layouts are adjustable.

## PC

| Action | Default |
|---|---|
| Move | **W A S D** |
| Look | **Mouse** |
| Jump | **Space** |
| Sprint | **Shift** |
| Crouch | **Ctrl** |
| Interact / search | **E** |
| Use equipped item | **Left Click** |
| Aim (pistol) | **Right Click** |
| Fire (pistol) | **Left Click** |
| Inventory | **I** |
| Case File | **Tab** |
| Evidence Board | **B** (near the board) |
| Map | **M** |
| Ping / marker | **Q** |
| Voice chat | **V** (hold or toggle) |
| Text chat | **T** |
| Emote | **G** |
| Scoreboard | **Tab** (hold) |
| Menu | **Esc** |

## Mobile

| Action | Control |
|---|---|
| Move | Left virtual joystick |
| Look | Drag on screen |
| Interact | Tap the prompt |
| Use item | Tap the item button |
| Inventory | Backpack button |
| Case File | Case File button |
| Map | Map button |
| Ping | Ping button |
| Voice | Microphone button |
| Chat | Chat button |

**Mobile tips:**
- Increase the interaction prompt size in **Settings → Accessibility**.
- Use the **tap-to-move** option if the joystick is uncomfortable.
- The Case File and evidence board support large text.

## Gamepad

| Action | Default |
|---|---|
| Move | Left stick |
| Look | Right stick |
| Interact | **X / Square** |
| Use item | **R2 / RT** |
| Inventory | **Y / Triangle** |
| Case File | **LB / L1** |
| Map | **RB / R1** |
| Ping | **D-pad up** |
| Voice | **D-pad down** |
| Chat | **View / Select** |

Gamepad support is **recommended** for players who prefer sitting back. The UI supports focus navigation.

## Contextual prompts

The game shows a prompt when you are near something you can use:

- **Search** — a container, drawer, or prop.
- **Read** — a document, plaque, or letter.
- **Talk** — an NPC.
- **Pick up** — an item or dropped gun.
- **Trade** — another player.
- **Submit** — the Case File or evidence board.
- **Channel** — the ritual altar.
- **Break sigil** — the physical sigil.

Hold the interact key for actions that take time. A progress ring shows the duration.

## The Case File

- Open with **Tab** (PC), the Case File button (mobile), or **LB** (gamepad).
- The four tasks are listed on the left.
- Each task shows your free clue, your item clue (if found), and three answer options.
- Select an answer and confirm. The first submission locks the task.
- The letter you earn is shown in the **Hollow Word** section.

## The evidence board

- The physical board is in the foyer.
- Stand near it and press **B** to open the close-up view.
- Pin clues, connect them with string, and compare testimonies.
- The board is shared by the whole team.

## Voice and text

- **Voice chat** is off by default until you opt in.
- **Text chat** always works.
- **Ping** marks a location for your team.
- **Emotes** are cosmetic and safe to use without voice.

## Spectator (ghost)

| Action | Default |
|---|---|
| Fly | **W A S D** |
| Look | **Mouse** |
| Ascend / descend | **Space / Ctrl** |
| Switch target | **Q / E** |
| Dead chat | **T** |
| Exit spectate | **Esc** |

Ghosts cannot interact with the world. The controls are for observation only.
